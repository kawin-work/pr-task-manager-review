# PR Task Manager Review

prototype ระบบรับคำสั่งงาน (work order) ของส่วนงานสื่อสารองค์กร สภาวิชาชีพบัญชี พร้อมเลเยอร์คอมเมนต์แบบ Figma สำหรับทีมและ developer

## สำหรับ developer

- เปิด `index.html` (หรือหน้า GitHub Pages) แล้วใช้งาน prototype ได้ตามปกติ
- ส่วนที่มีคอมเมนต์จะมี **กรอบเส้นประ** และ **หมุดตัวเลข** ตรงจุดนั้น เมนูด้านซ้ายมี **ป้ายจำนวนคอมเมนต์** ของแต่ละหน้า
- กดคอมเมนต์ในรายการหรือหน้าสรุป ระบบจะพาไปที่จุดนั้นเอง (สลับผู้ใช้ เปิดหน้า หรือเปิดงานที่ตรงสถานะให้) แล้วกะพริบกรอบสีตามสถานะ
- ตอนเขียนคอมเมนต์ เลือกได้ว่า **ให้ Claude ขยายความ** หรือ **ไม่ต้องขยาย** (บนหน้า GitHub คอมเมนต์ที่ขอให้ขยายจะเข้าคิว "รอขยาย" ในคอลัมน์ "ให้ Claude ขยาย" ของ Sheet)
- แก้โน้ตที่เขียนไปแล้วได้ กด **แก้ไข** ในคอมเมนต์ แล้วเลือกเก็บรายละเอียดเดิม ขยายใหม่ หรือไม่ต้องขยาย
- กด **สรุป** ที่แถบด้านล่าง (หรือเปิดลิงก์ `#summary`) เพื่อดูคอมเมนต์ทั้งหมด แยกตามหน้าจอและสถานะ
- คอมเมนต์ที่ขยายแล้วมี 5 หัวข้อ: เปลี่ยน · เหตุผล · กระทบส่วนอื่น · ถือว่าเสร็จเมื่อ · รอตัดสิน
- สลับบทบาท (ผู้สั่งงาน / เจ้าหน้าที่ / หัวหน้า / admin) ที่มุมขวาบนของ prototype เพื่อดูหน้าของแต่ละบทบาท

## ข้อมูลคอมเมนต์

- คอมเมนต์ทั้งหมดเก็บใน Google Sheet "PR Task Manager — Review Comments" (บัญชี prdrive.2018) เปิดจากเครื่องไหนก็เห็นชุดเดียวกัน หน้าเว็บดึงข้อมูลใหม่ทุก ~12 วินาที
- คอมเมนต์ครั้งแรกให้ใส่ชื่อ (จำไว้ในเครื่องนั้น) ทุกคนที่เปิดหน้านี้เขียนคอมเมนต์ได้
- เปลี่ยนสถานะได้ทั้งในหน้าเว็บและใน Sheet (คอลัมน์ "สถานะ" เป็น dropdown)
- ระบบหลังบ้านคือ Apps Script ที่ผูกกับ Sheet นั้น (Code.gs ใน repo นี้) ถ้าแก้โค้ดต้อง Deploy เวอร์ชันใหม่ใน Apps Script
- สัญลักษณ์บนหน้าจอดูได้จากกล่อง "สัญลักษณ์คอมเมนต์" ในแถบเมนูซ้าย
